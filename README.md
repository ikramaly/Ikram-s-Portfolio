# Ikram Ali | Developer Portfolio

A modern and responsive personal portfolio website built to showcase my skills, projects, academic background, and journey as a Java Full Stack Developer.

### 🌐 Live Preview
[**View My Portfolio**](i_will_add_link_here)

### ✨ Features
- Modern dark theme with responsive UI
- About Me and technical skills
- Projects with screenshots and GitHub links
- Education and academic achievements
- Contact details and social media links
- Downloadable resume

### 🛠️ Tech Stack
React.js · JavaScript · Tailwind CSS · Vite · React Icons

### 🚀 Run Locally
```bash
git clone https://github.com/ikramaly/ikram-portfolio.git
cd ikram-portfolio
npm install
npm run dev
```
